# Instrucciones de Contribución
Este es el reglamento diseñado para mantener un orden en el proyecto. A continuación se verá la forma de proceder según qué añadan:
## Reglas Generales
- No le muevas a una rama sin autorización de un encargado
- Si le vas a mover y no eres encargado de esa rama, crea una rama secundaria a partir de esa rama (ej. si vas a hacer algo en la rama "foo" debes hacerlo en una nueva rama llamada "foo/cosa_que_quieres_hacer") y luego avisa al encargado para que intente mezclarla
